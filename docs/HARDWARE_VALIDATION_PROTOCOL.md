# STC32 实机验证记录模板

本模板用于未来在专用测试板上收集证据。填写前必须明确同意可能的 Flash/EEPROM 修改；当前插件不会自动执行这些步骤。

## 只读阶段

- 芯片：STC32G12K128
- BSL 版本：7.4.5U
- 串口：记录实际 COM 号和 CH340 VID/PID
- HEX：记录文件 SHA-256、地址最小值/最大值和分块摘要
- 操作：打开串口后等待提示，再按一次 RES
- 记录：原始状态 payload、设备响应、串口释放结果

## 写入前固定条件

- 使用可恢复的专用测试板，不使用唯一开发板；
- 保存原始工程、HEX 和当前状态记录；
- 明确 EEPROM 是否允许擦除；默认不允许；
- 明确硬件选项是否允许修改；默认不允许；
- 关闭官方 STC-ISP，避免两个程序争用串口；
- 记录每个命令的发送帧、应答帧、超时和断线状态。

## 验证顺序

1. 只读握手与状态读取；
2. 不写入的帧格式/校验模拟；
3. 受控擦除测试（单独授权）；
4. 小型测试程序写入（单独授权）；
5. 设备端确认或真实回读；
6. 断线、中止、错误应答恢复；
7. 重新上电后确认复位脚、EEPROM 和应用运行状态。

任何一步缺少可重复记录，都不能把独立烧录按钮改为可用。
